# Tic Tac Toe - Android App

This is an Android implementation of the classic Tic Tac Toe game.

## 📥 Download the APK
Click the link below to download and install the app:
- [Download Tic Tac Toe APK](https://github.com/yogeshdangii/tictactoe-android/raw/refs/heads/main/app/release/app-release.apk)

## 🎮 Features
- play against a friend
- Simple and intuitive UI.
- Lightweight and fast.



## 🚀 How to Install
1. Download the APK file from the link above.
2. Allow installation from unknown sources in your device settings.
3. Open the APK file and follow the on-screen instructions.
